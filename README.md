# UESRPG 3e v4 Character Sheet App

A desktop application built with Python and Tkinter for managing character sheets in the **UESRPG 3e v4** (Unofficial Elder Scrolls Roleplaying Game) tabletop system.

## Features

* **Interactive Character Sheet**: Easily track statistics, attributes, equipment, talents, traits, and magic.
* **Smart Attribute Logic**: Enforces a maximum of 2 *Favored Attributes* with built-in validation.
* **Spell Management**: Specialized 3x7 dynamic spell grid cards with full description fields.
* **JSON Import & Export**: Save and load your character progress seamlessly at any time.
